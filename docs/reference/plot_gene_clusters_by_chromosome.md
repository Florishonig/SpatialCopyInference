# Plot genomic clusters by chromosome

Generates chromosome-level visualisations of genomic clusters identified
by identify_gene_clusters().

Differentially expressed genes are displayed along the genomic
coordinate space of each chromosome and coloured according to the size
of the cluster to which they belong. Genomic cluster boundaries are
highlighted, and optional genomic density tracks and driver gene
annotations can be overlaid. One figure is generated per chromosome.
Plots can be displayed in the active graphics device or saved to a
specified output directory.

## Usage

``` r
plot_gene_clusters_by_chromosome(
  gene_clusters,
  chromosome = NULL,
  density = NULL,
  driver_genes = NULL,
  raised_driver_genes = NULL,
  output_dir = NULL
)
```

## Arguments

- gene_clusters:

  Output from identify_gene_clusters()

- chromosome:

  Optional chromosome or vector of chromosomes to plot (e.g. "chr3" or
  c("chr3", "chr8")). If NULL, all chromosomes are plotted

- density:

  Optional genomic density signal generated by plot_gene_density()

- driver_genes:

  Optional vector of driver genes to annotate

- raised_driver_genes:

  Optional subset of driver genes displayed on a separate annotation
  track to reduce label overlap

- output_dir:

  Optional directory in which chromosome plots will be saved. If NULL,
  plots are displayed in the active graphics device.

## Value

An invisible list containing the annotated differentially expressed gene
ranges (`gr_de`) and driver gene ranges (`gr_drivers`) used for
visualisation.
