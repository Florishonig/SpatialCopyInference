# Plot example cell profiles

Plots gene-level expression and chromosome arm-level expression profiles
for a selected cell.

Gene expression values are displayed across the genome together with
chromosome arm means and reference chromosome arm expression levels.

## Usage

``` r
plot_cell_profiles(xenium.obj, cell_id, arm_means_matrix, reference)
```

## Arguments

- xenium.obj:

  Normalised Xenium object

- cell_id:

  Cell identifier to plot

- arm_means_matrix:

  Matrix of chromosome arm mean expression values generated by
  compute_arm_means().

- reference:

  Reference chromosome arm profile generated by compute_reference().

## Value

A ggplot2 object showing gene-level expression together with chromosome
arm-level and reference expression profiles for a selected cell.

## Examples

``` r
if (FALSE) { # \dontrun{
# Plot example cell profile
plot_cell_profiles(xenium.obj = xenium.obj,
                  cell_id = "aamfeehk-1",
                  arm_means_matrix = arm_means_matrix,
                  reference = epithelium_ref_arm_means)} # }
```
