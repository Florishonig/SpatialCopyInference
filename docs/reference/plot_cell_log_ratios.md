# Plot example cell log ratios

Plots gene-level and chromosome arm-level log ratio profiles for a
selected cell.

Gene expression values are centred relative to a reference population
and displayed across the genome together with chromosome arm-level log
ratio values.

## Usage

``` r
plot_cell_log_ratios(xenium.obj, cell_id, arm_ratios, reference_groups)
```

## Arguments

- xenium.obj:

  Normalised Xenium object

- cell_id:

  Cell identifier to plot

- arm_ratios:

  Matrix of chromosome arm log ratio values generated by
  compute_arm_ratios().

- reference_groups:

  Groups used to construct the reference population for gene-level log
  ratio calculation.

## Value

A ggplot2 object showing gene-level and chromosome arm-level log-ratio
profiles for a selected cell.

## Examples

``` r
if (FALSE) { # \dontrun{
# Plot example log ratio cell profile
plot_cell_log_ratios(xenium.obj = xenium.obj,
                    cell_id = "aamfeehk-1",
                    arm_ratios = arm_ratios,
                    reference_groups = c("Fallopian Tube Epithelium",
                    "Secretory Epithelial Cells"))} # }
```
