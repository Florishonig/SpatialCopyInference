# Plot cluster heatmaps

Visualises average chromosome arm log ratio profiles for BANKSY-derived
spatial clusters.

For each clustering resolution, chromosome arm log ratios are averaged
across cells within each cluster and displayed as a heatmap.

## Usage

``` r
plot_cluster_heatmaps(BANKSY.obj, resolutions = c(0.1))
```

## Arguments

- BANKSY.obj:

  Seurat object generated by compute_spatial_clusters().

- resolutions:

  Clustering resolutions to plot.

## Value

A list of ComplexHeatmap heatmap objects, with one heatmap per
clustering resolution.

