# Compute spatial clusters

Performs spatial clustering of inferred chromosome arm log ratio
profiles using the BANKSY algorithm.

The resulting clusters represent spatially organised groups of cells
with similar somatic copy number aberration profiles.

## Usage

``` r
compute_spatial_clusters(
  arm_ratios,
  xenium.obj,
  lambda = 0.8,
  k_geom = 30,
  dims = 1:8,
  k_param = 30,
  resolution = 0.1,
  seed = 1
)
```

## Arguments

- arm_ratios:

  Matrix of chromosome arm log ratio values generated by
  compute_arm_ratios()

- xenium.obj:

  Normalised Xenium object

- lambda:

  BANKSY spatial weight parameter

- k_geom:

  Number of spatial neighbours used by BANKSY.

- dims:

  Principal components used by Seurat::FindNeighbors()

- k_param:

  Number of neighbours used by Seurat::FindNeighbors()

- resolution:

  Resolution parameter used by Seurat::FindClusters()

- seed:

  Random seed used by Seurat::FindClusters()

## Value

A Seurat object containing BANKSY-derived spatial clusters.

## References

Singhal, V., Chou, N., Lee, J. et al. BANKSY unifies cell typing and
tissue domain segmentation for scalable spatial omics data analysis.
Nature Genetics 56, 431-441 (2024).
<https://doi.org/10.1038/s41588-024-01664-3>
