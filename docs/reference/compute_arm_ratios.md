# Compute chromosome arm ratios

Computes chromosome arm log ratio profiles by subtracting a reference
chromosome arm expression profile from chromosome arm mean expression
values.

## Usage

``` r
compute_arm_ratios(
  arm_means_matrix,
  xenium.obj,
  group_var = NULL,
  reference = NULL
)
```

## Arguments

- arm_means_matrix:

  Matrix of chromosome arm mean expression values generated by
  compute_arm_means().

- xenium.obj:

  Normalised Xenium object.

- group_var:

  Optional metadata variable used to define reference cells. If NULL,
  all cells are used.

- reference:

  Optional groups within group_var used to construct the reference
  chromosome arm profile. If NULL, all cells (or all groups within
  group_var) are used.

## Value

A matrix of chromosome arm log ratio values with chromosome arms as rows
and cells as columns.

## Examples

``` r
if (FALSE) { # \dontrun{
# Compute chromosome arm ratios using specific reference(s)

                                xenium.obj,
                                group_var = "group",
                                reference = c("Fallopian Tube Epithelium",
                                "Secretory Epithelial Cells"))

# Compute chromosome arm ratios using global mean
arm_ratios <- compute_arm_ratios(arm_means_matrix,
                                xenium.obj)} # }
```
