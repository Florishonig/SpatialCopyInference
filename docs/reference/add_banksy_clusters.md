# Add BANKSY clusters to Xenium object

Adds BANKSY-derived spatial cluster to the metadata of a Xenium object.

Cluster assignments generated by compute_spatial_clusters() are
transferred from a BANKSY object to the original Xenium object for
downstream visualisation and analysis.

## Usage

``` r
add_banksy_clusters(
  xenium.obj,
  BANKSY.obj,
  resolution = 0.1,
  metadata_name = "banksy_clusters"
)
```

## Arguments

- xenium.obj:

  Xenium object

- BANKSY.obj:

  Seurat object generated by compute_spatial_clusters()

- resolution:

  Clustering resolution used during compute_spatial_clusters()

- metadata_name:

  Name of the metadata column used to store cluster assignments

## Value

Xenium object with BANKSY-derived spatial clusters added to the
metadata.
